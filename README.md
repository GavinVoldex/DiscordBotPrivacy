# Privacy Policy for UF Discord Bot

**Bot Name:** UF
**Last Updated:** August 31, 2026

## Data Collection

The bot collects:

- **Discord user IDs** — used to identify who ran a command, to write staff audit records, and to store per-user game records such as `/tossup` win-loss counts.
- **Discord server and channel IDs** — recorded alongside command usage in our staff audit log so staff can see where an action was taken.
- **Command inputs** — the text and options you pass to a slash command are processed to generate a response, and are recorded in the staff audit log.
- **Linked Roblox account details** — for members who have linked a Roblox account through Bloxlink, or whose server nickname identifies their Roblox account, we resolve the associated Roblox username and user ID in order to apply in-game benefits and to authorise staff commands.
- **Moderation records** — when a staff member issues a ban, unban, kick, mute or warning through the bot, we record the target's Roblox user ID, the acting moderator's Roblox user ID, the reason given, the duration and a timestamp.

The bot uses slash commands only. It does not read, parse, store or respond to ordinary chat messages, and it does not use the Message Content intent.

The bot does not collect passwords, payment information, email addresses, direct messages, voice data, or any data for advertising or profiling.

## How the Data Is Used

Collected information is used for operational purposes only: to run the bot's features, to grant and revoke in-game benefits for subscribers and server boosters, to authorise and record staff moderation actions, and to prevent abuse.

Data is never sold, and is not shared with third parties except where required by law.

## Storage and Retention

Data is held on infrastructure controlled by the bot operator, and is kept only as long as it is needed:

- **Game records.** Discord user IDs and `/tossup` win-loss counts are stored in a private database and retained while the leaderboard is active.
- **Benefit entitlements.** For members entitled to in-game benefits, a Roblox user ID and a numeric subscription tier are stored in the game's datastore. The record is deleted when the entitlement ends — when a subscription lapses or a member stops boosting the server.
- **Moderation records.** Moderation history is retained for as long as it is needed to enforce the game's rules and to review appeals.
- **Audit logs.** Command usage records are retained in a private staff channel.

## Data Deletion

You can request deletion of your data at any time by opening a ticket in the NFL Universe Football Discord server. Removing the bot from a server stops any further collection from that server.

## Third-Party Services

The bot operates on Discord and is subject to Discord's [Terms of Service](https://discord.com/terms) and [Privacy Policy](https://discord.com/privacy). Roblox account linking is provided by Bloxlink, and in-game data is stored through Roblox. Use of those services is subject to their own terms.
